Built to stay out of your way

Deterministic keyword scoring with sensible defaults — no AI guesswork, no accounts, no tracking.

Deterministic by design

Classification matches the CLI 1:1. When scores tie, earlier vibes win. Below the minimum threshold, your music stays put.

Shareable by default

Every classification has a ?task= shareable link. Send a task's vibe to someone else with one click.

Works with agents

Drop in the OpenCode plugin and TaskFM auto-picks the right vibe when you start a new task — zero friction.

Client-side only

Static, fast, and private. No backend, no auth, no telemetry. Runs entirely in your browser.

Install the CLI

Use TaskFM in your terminal or hook it into your coding agent to auto-play the right vibe when you start work.

uv tool install git+https://github.com/arjunkshah12345-hash/taskfm
pipx install git+https://github.com/arjunkshah12345-hash/taskfm
python3 -m pip install --user git+https://github.com/arjunkshah12345-hash/taskfm
1 taskfm doctor — verify setup
2 taskfm start "fix the flaky websocket reconnect bug" — try it
3 taskfm vibe "write the readme" — preview without playing

Hook into your agent

TaskFM stays out of the way — same-vibe cooldown prevents restarts, and vague prompts don't change your music.

OpenCode (automatic)
mkdir -p ~/.config/opencode/plugins
curl -o ~/.config/opencode/plugins/taskfm.js \
  https://raw.githubusercontent.com/arjunkshah12345-hash/taskfm/main/adapters/opencode/taskfm.js

Works with stdin prompts too: echo '{"prompt":"review the PR"}' | taskfm start

Try "debug memory leak", "deploy to production", or "write the README"
